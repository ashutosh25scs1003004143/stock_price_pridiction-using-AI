# AI Stock Predictor 📈

A professional, full-stack AI-powered Stock Price Prediction and Financial Analytics Web Application built with Streamlit, Python, Scikit-learn, and Plotly. Suitable for college major projects and technical portfolios.

## Features
- **Interactive Dashboard:** Real-time metrics and historical charts.
- **Technical Analysis:** SMA, RSI, and MACD indicators.
- **Machine Learning Engine:** Linear Regression & Random Forest models with chronological splitting and 7-day recursive forecasting.
- **Stock Comparison:** Relative percentage performance analysis.
- **Watchlist & History:** Track benchmark stocks and export session predictions.
